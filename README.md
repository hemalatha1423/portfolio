# Hemalatha D Portfolio

This portfolio was customized from the uploaded vCard-style HTML template using the information in the latest resume.

## Files
- index.html — portfolio content and structure
- style.css — responsive dark portfolio design
- script.js — navigation between sections

## Run
Open `index.html` in any modern browser.

## Before publishing
1. Add your professional photo if you want one.
2. Add your LinkedIn URL.
3. Add your GitHub URL.
4. Add project GitHub/demo links if available.
5. Optionally connect the contact form to a backend or form service.
